Projeto Tédio

Sobre o projeto
O Projeto Tédio é uma aplicação web desenvolvida para refletir sobre a importância do tédio e dos momentos sem estímulos no dia a dia.

A aplicação apresenta informações sobre o tema e permite que o usuário navegue entre diferentes seções de forma simples e organizada.

Objetivo
O objetivo do projeto é apresentar uma reflexão sobre como o excesso de notificações, vídeos e redes sociais pode diminuir os momentos de tédio e de pausa.

Tecnologias utilizadas
HTML5
CSS3
JavaScript
Git
GitHub

Estrutura do projeto

O projeto possui a seguinte estrutura:

`INDEX.HTML` — estrutura principal da aplicação.
`STYLE.CSS` — estilos e aparência da aplicação.
`JS/` — arquivos JavaScript responsáveis pelas funcionalidades e interação da aplicação.
